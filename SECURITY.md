# Política de seguridad

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad, **no abras un issue público**. Usa el reporte privado de GitHub:
pestaña *Security* → *Report a vulnerability*.

Se responderá en la medida de lo posible. Este es un proyecto académico mantenido por voluntarios.

## Alcance

Este repositorio contiene el recolector de métricas de GitHub y el diseño de datos. No contiene credenciales:
las claves viven en Secret Manager y los archivos `.env` están excluidos del control de versiones.

Si ves un secreto expuesto en el historial, repórtalo por el mismo canal.
